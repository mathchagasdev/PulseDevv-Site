# PulseDevv – Site

Site institucional da PulseDevv. É um único arquivo: `index.html` (HTML + CSS + JS, sem build).

## Como editar
1. `git pull` antes de começar
2. Edite o `index.html` e abra no navegador para conferir
3. `git add . && git commit -m "o que mudou" && git push`

## Onde mudar
- Número do WhatsApp: `const WHATSAPP` no final do arquivo
- Cor de destaque: `--accent` no início do `<style>`
- E-mail de contato: procure `contato@pulsedevv.com`

## Publicação
Hostinger → hPanel → Avançado → GIT, apontando para a branch `main` e a pasta `public_html`.
